# Personalized-AI-for-Parkinson-s-Patient
I explored the intersection of Biomedical Signal Processing (DSP), Human-Computer Interaction (HCI), and Prompt Engineering (LLMs) to address a critical question: how can continuous smartwatch accelerometry be converted into grounded, accessible narratives for patients and neurologists without causing clinical hallucinations?

An exploratory Human-Computer Interaction (HCI) and digital health project investigating how different data representations of wrist-worn accelerometry influence narrative generation, numerical grounding, uncertainty calibration, and clinical safety in Large Language Models (LLMs).

Developed within the Summer of Research 2026 at LASIGE — Faculdade de Ciências da Universidade de Lisboa (FCUL) under the mentorship of Prof. Diogo Branco.

📌 Context & Motivation

Clinical follow-up consultations in Parkinson's Disease (PD) typically last between 10 and 15 minutes. During these brief windows, patients struggle to accurately recount weeks of motor fluctuations due to retrospective recall fatigue.

While commercial wrist wearables (smartwatches) can continuously capture longitudinal movement in free-living environments, displaying raw sensor time-series or complex Fourier graphs causes cognitive overload for patients and is unusable during short clinical encounters.

This project addresses the communication gap:

Core Research Question: How does the representation and contextualisation of Parkinson's wearable data affect the groundedness, usefulness, uncertainty, and clinical safety of narratives generated by a large language model?

🏗️ System Architecture

The framework decouples high-throughput numerical signal processing from natural language generation into a two-layer pipeline:

+-----------------------------------------------------------------------------------+
|                        DETERMINISTIC LAYER (Offline DSP)                          |
|                                                                                   |
|  [Triaxial Accelerometry @ 100 Hz] (~307 hours across 3 recordings)               |
|       │                                                                           |
|       ├──> 4th-order Butterworth High-Pass Filter (fc = 0.5 Hz, gravity removal)  |
|       ├──> Dynamic Vector Magnitude: SVM_dyn(t) = sqrt(x^2 + y^2 + z^2)           |
|       ├──> Sliding Windowing (4.0 s window, 50% overlap / 2.0 s step)             |
|       └──> Heuristic Feature Extraction:                                          |
|                 ├── Rest Tremor (Welch PSD peak in 4.0–6.0 Hz + RMS rest ceiling)  |
|                 ├── Bradykinesia (0.2–4.0 Hz band, amplitude drop >= 75%)         |
|                 └── Dyskinesia (0.5–4.0 Hz, spectral entropy >= 0.7, gait reject) |
|                                                                                   |
|            [Multi-Symptom Summary Vector (MSSC)]                                  |
|            (% Calibrated Calm, % Tremor, % Bradykinesia, % Dyskinesia)            |
+------------------------------------------┬----------------------------------------+
                                           │
                                           ▼
+-----------------------------------------------------------------------------------+
|                     GENERATIVE LAYER (openai/gpt-oss-120b)                        |
|                                                                                   |
|  Structured Prompt (European Portuguese / English)                                |
|    + Strict Negative Constraints (No diagnosis, no drug causality, uncertainty)   |
|                                           │                                       |
|                                           ▼                                       |
|  [Tripartite Clinical Consultation Summary]                                       |
|    1. A Tua Semana em Poucas Palavras (Empathetic, non-stigmatising review)       |
|    2. Para Refletires (Episodic memory recall questions)                          |
|    3. O Que Levar para a Conversa com o Médico (Concise 2-min consultation brief)
